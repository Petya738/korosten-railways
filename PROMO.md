# Korosten Railways — бриф для ИИ-рекламы

## Что рекламируем

Фанатский железнодорожный проект в Roblox.

- Сайт: https://petya738.github.io/korosten-railways/
- Telegram: @urztuk
- Готовая станция: Голендри
- В планах: Вінниця
- Маршрут: Кордишовка — Винница
- Стиль: чёрно-белая железная дорога, тёмное «стекло», интерфейс как в iOS
- Языки: RU / UA
- Тема: тёмная

## Что отдать ИИ

Безопасно отдавать только папку `korosten-railways-site`:

- `index.html`
- `assets/hero.jpg`
- скриншоты сайта (главная, сник пик, связь, сотрудничество)
- этот файл

**Не отдавай:** `config.json`, папку `inbox`, личные фото и файлы из `Downloads`.

## Ролик 15–20 секунд (9:16)

1. **0–2 с.** Чёрный экран. Звук проходящего поезда. Появляется белый текст: `KOROSTEN RAILWAYS`.
2. **2–5 с.** Ч/б кадр путей с фонового фото, медленный проезд камеры вперёд.
3. **5–9 с.** Карточки: `ГОЛЕНДРИ · готовая станция`, `ВІННИЦЯ · в планах`, `КОРДИШОВКА — ВИННИЦА · маршрут`.
4. **9–13 с.** Телефон в руке: нижний таскбар с четырьмя вкладками и переключение языка RU/UA. Крупно — «стеклянный» интерфейс.
5. **13–16 с.** Экран «Связь»: `@urztuk`, форма «Идея, пожелание или баг»; затем вкладка «Сотрудничество» и кнопка «Следить за обновлением» → `t.me/KorostenRailways`.
6. **16–20 с.** Логотип, `KOROSTEN RAILWAYS`, `t.me/urztuk`, URL сайта. Кнопка/подпись: «Смотри проект».

## Практика

- Генерируй **видео без текста**, а надписи добавляй в CapCut / Premiere / Canva — ИИ часто ломает буквы.
- Форматы: 9:16 для Reels/TikTok/Shorts, 16:9 для YouTube, 1:1 для постов.
- Музыка: бери лицензионную или трендовую из библиотеки редактора.
- Для превью: скриншот главной + крупный текст `KOROSTEN RAILWAYS`.
- Хорошие инструменты: Kling, Runway, Pika, Sora — видео; CapCut — монтаж и субтитры; Canva — обложки; ElevenLabs — озвучка.
- Покажи 2–3 версии: «атмосфера» (медленно, кинематографично) и «динамика» (быстрый монтаж под бит).
