## GitHub Pages

Сайт публикуется статически: `index.html` + `assets/`. Форма на публичной версии
не может отправлять запросы на локальный сервер, поэтому она предложит скопировать
текст и открыть Telegram. Полная отправка в `inbox` и Telegram-бота работает при
локальном запуске.

## Локальный запуск

```powershell
python server.py
```

Сайт: `http://127.0.0.1:8787/`

Сообщения сохраняются в `inbox/`. Для Telegram-бота скопируй `config.example.json`
в `config.json`, вставь `bot_token` и `chat_id`, перезапусти сервер.
